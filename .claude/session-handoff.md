# session-handoff — ArticleStudio
(يُعاد كتابته في نهاية كل جلسة، 25 سطراً كحد أقصى)

- الحالة: v0.7.0: نشر مباشر مراحل (…رفع الصور ← تأكيد ظهورها ← نشر) عبر Blogger API بحساب جوجل فقط؛ دليل الربط داخل التطبيق (زر «النشر» في بطاقة الموقع)؛ نشر ملف XML يدوياً.
- القرارات: حُذف جسر Apps Script (لا خدمة Blogger فيه) وأُلغي النشر بالبريد (بلا تصنيفات/رابط/جدولة)؛ الجدولة مسودة ثم publish بتاريخ؛ الافتراضي «مسودة»؛ يتطلب رفع الصور التلقائي؛ مقال له `remote_url` يُتخطّى.
- قيد: الـ API لا يضبط الرابط الدائم ولا وصف الميتا (XML يضبطهما).
- تحقق فعلياً: 55 اختبار وحدة خضراء، debug وrelease يبنيان.
- لم يُتحقق: نشر حقيقي، موافقة جوجل على جهاز، الجدولة الفعلية، بقاء JSON-LD في المنشور.
- على ساجد: إلغاء الـ PAT المكشوف؛ مفاتيح المزودين؛ توكن GitHub؛ مشروع Cloud + مستخدم تجريبي ثم «ربط حساب جوجل» وتجربة مسودة.
- الخطوة التالية: تثبيت v0.7.0، ربط مدونة، توليد مقال وتصدير ومراجعة المسودة في بلوجر.
