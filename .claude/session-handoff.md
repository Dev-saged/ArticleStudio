# session-handoff
- الحالة: main = v0.16.0 (versionCode 20): طابور بأقسام لكل منصة مع «نشر الآن» و«نشر الكل» بفاصل؛ قبله v0.15.0: مركز المشاركة (الحسابات، المقالات، الطابور، الإعدادات) + إنستغرام بالصورة + خزنة كوكيز مشفرة.
- تحقق: 140 اختبار Kotlin تقريباً + 12 jsdom + assembleDebug أخضر. جديد: كوكيز الجلسة، tgFail، catchUp، shareNow، setCredentials (كلها باختبارات).
