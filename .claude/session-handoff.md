# session-handoff — ArticleStudio
(يُعاد كتابته في نهاية كل جلسة، 25 سطراً كحد أقصى)

- الحالة: v0.8.0: بعد اكتمال التوليد يعمل المسار تلقائياً (تصدير ← رفع صور ← تأكيد ← نشر) داخل `JobRunner` عبر `PostRun`؛ مؤقت توليد دوري لكل موقع (`auto*` في SiteConfig) بـ WorkManager.
- النشر على بلوجر عبر Blogger API بحساب جوجل فقط؛ نجح فعلياً عند ساجد في v0.7.0.
- القرارات: المسار مفعّل افتراضياً (`autoExport`)؛ إعادة محاولة تلقائية 4×دقيقة عند تأخر الصور؛ الدورة المستحقة تبدأ بنفس مزودات الموقع ووضعه.
- تحقق فعلياً: 60 اختبار وحدة خضراء، debug وrelease يبنيان.
- لم يُتحقق: المؤقت الدوري على جهاز حقيقي (Doze/توفير البطارية)، المسار الكامل بمزودات حقيقية.
- على ساجد: تعطيل تحسين البطارية للتطبيق ليعمل المؤقت؛ ضبط «توليد تلقائي كل كم ساعة» في إعدادات الموقع.
- الخطوة التالية: تجربة دورة واحدة كل ساعة بمقالين وملاحظة السجل والإشعار.
