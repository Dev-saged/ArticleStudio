# session-handoff — ArticleStudio
(يُعاد كتابته في نهاية كل جلسة، 25 سطراً كحد أقصى)

- الحالة: v0.6.0 على `feature/publish`: نشر مباشر على بلوجر بعد التصدير لكل موقع، بطريقتين (جسر Apps Script، أو Blogger API بتسجيل دخول جوجل)، مع دليل ربط داخل التطبيق (زر «النشر» في بطاقة الموقع)، ونشر ملف XML يدوياً أو من «ملفاتي المصدّرة».
- القرارات: الحالة الافتراضية «مسودة»؛ النشر يتطلب رفع الصور التلقائي؛ السر لكل موقع مشفّر؛ البصمة SHA-1 تُعرض من التطبيق نفسه؛ مقالات تُتخطّى إن كان لها `remote_url`.
- قيد معروف: الـ API لا يضبط الرابط الدائم ولا وصف الميتا، والـ XML يضبطهما.
- تحقق فعلياً: 58 اختبار وحدة خضراء (ناشران بخادم وهمي، XmlImport، ترحيل 3→4، قواعد المواقع)، debug وrelease.
- لم يُتحقق: نشر حقيقي بأي من الطريقتين، موافقة جوجل على جهاز حقيقي، سلوك التاريخ المستقبلي، بقاء JSON-LD داخل المنشور.
- على ساجد: إلغاء الـ PAT المكشوف؛ مفاتيح المزودين؛ توكن GitHub؛ تجربة جسر Apps Script على مدونة واحدة بحالة «مسودة».
- الخطوة التالية: تثبيت v0.6.0، ربط مدونة بالجسر، توليد مقال وتصدير ومراجعة المسودة في بلوجر.
