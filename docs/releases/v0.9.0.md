# ArticleStudio v0.9.0

## الإضافات
- زر «تعبئة تلقائية» في محرر الموقع: يقرأ مدونتك (التغذية أو الصفحة) ويملأ المجال والوصف والتصنيفات والجمهور والنبرة والطول والكلمات المفتاحية والمصادر دفعة واحدة، مع تحسين اختياري بالنموذج.
- محرر موقع بورقة واحدة مرتبة بدل الشاشات المتفرقة؛ مؤقت التوليد الدوري داخل كل موقع ويُحفظ معه.
- المقال المكرر يُستثنى مباشرة قبل التوليد وبعده كحالة «مكررة مستثناة» (نجاح محايد) لا فشل، مع سبب المطابقة وزر «ولّد رغم التكرار».
- تصميم صور جديد: 4 تخطيطات و8 أنماط خلفية حسب مجال الموقع وألوان مشتقة من المقال فلا تتكرر الصور، ولوحة قناة فخمة في كل غلاف: شعار باسم القناة، الاسم، ورابط القناة.

## المميزات
- شاشة «التصدير» صارت «السجل والنشر»: النتائج أولاً، الزر الوحيد يظهر فقط إن بقي ما ينتظر، والملفات وإعدادات GitHub والنشر اليدوي في أقسام مطوية.
- الرئيسية: عدّاد المكرر المستثنى وسطر المكرر بلون هادئ، والتقدم يحتسبه.

## الإصلاحات
- سبعة رموز أغلفة (تقنية، صحة، طعام، اقتصاد، سفر، تعليم) كانت تفشل في الرسم بسبب تدرّج في الحد؛ أصبحت تُرسم وعليها اختبار.
