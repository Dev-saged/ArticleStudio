# v0.14.0

## الإضافات
- مركز «مشاركة المقالات»: حسابات لكل منصة (فيسبوك، X، ثريدز، لينكدإن، تيليغرام، بلوسكي) مع حالة وسقف يومي وفاصل ونافذة ساعات.
- حسابات الويب تُسجَّل مرة واحدة داخل التطبيق وتبقى الجلسة محفوظة لكل حساب.
- نشر تلقائي في الخلفية بعد نشر المقال عبر WorkManager، وطابور مع إعادة المحاولة والتخطي والنشر اليدوي.
- وصفات الواجهة بيانات قابلة للتحديث من GitHub دون إصدار جديد.

## المميزات
- عنوان قوي: 5 صياغات من المزوّد، تُقبل فقط إن بقيت وفية للعنوان ولم تخترع أرقاماً، مع احترام حد كل منصة.
- لا نشر مكرر: فهرس فريد (مقال، حساب) والمهمة المقطوعة تُركن لتدخلك.
- المسودات لا تُشارك؛ المجدولة تُشارك بعد موعد نشرها.
- مفتاح «شارك المقال على حساباتي» لكل موقع.
