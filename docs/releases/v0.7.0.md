# ArticleStudio v0.7.0

## الإضافات
- النشر المباشر مراحل ظاهرة في شريط التصدير: فحص GitHub، رسم الصور، رفع الصور، بناء XML، تأكيد ظهور الصور على الشبكة، ثم النشر على بلوجر.
- مرحلة «تأكيد ظهور الصور»: يفحص التطبيق أن غلاف أول وآخر مقال متاحان قبل نشر أي مقال، فلا تظهر منشورات بصور مكسورة.
- زر «متابعة النشر» إن تأخر ظهور الصور أو توقف النشر لصلاحية، فيكمل دون إعادة التصدير.
- جدولة صحيحة: المنشور يُنشأ مسودة ثم يُنشر بتاريخ مستقبلي عبر `publish` كما توثّق Blogger.

## المميزات
- طريقة نشر واحدة موثوقة: Blogger API الرسمي بحساب جوجل (تصنيفات، HTML، رابط كل منشور).
- أي موقع كان على «جسر Apps Script» يتحول تلقائياً إلى «متوقف» ليختار الربط بجوجل.

## الإصلاحات
- حذف جسر Apps Script لأن Apps Script لا يوفر خدمة Blogger («Blogger is not defined»).
- إلغاء فكرة النشر بالبريد بعد البحث: لا تصنيفات ولا رابط راجع ولا جدولة.
