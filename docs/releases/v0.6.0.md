# ArticleStudio v0.6.0

## الإضافات
- نشر مباشر على بلوجر تلقائياً بعد التصدير، لكل موقع حسابه ومدونته: عبر «جسر Apps Script» أو عبر «حساب جوجل» (Blogger API الرسمي).
- دليل ربط داخل التطبيق لكل طريقة بخطوات مرقّمة منفصلة، مع نسخ الكود واسم الحزمة وبصمة SHA-1 بضغطة، واختبار اتصال يُظهر اسم المدونة.
- حالة النشر لكل موقع: مسودة (الافتراضي)، نشر مباشر، أو مجدول.
- «نشر ملف XML من الجهاز» و«نشر» بجانب كل ملف في «ملفاتي المصدّرة».
- بطاقة نتيجة النشر: المنشور، المتخطّى، الأخطاء، وزر متابعة بعد ربط الحساب. وشارة «منشور على بلوجر» في المقالات.

## المميزات
- لا يُنشر المقال نفسه مرتين، وتُعاد المحاولة تلقائياً عند الأعطال المؤقتة، ويتوقف النشر فور خطأ صلاحية بدل تكرار الفشل.
- سر الجسر فريد لكل موقع ومشفّر على الجهاز.
- روابط «اقرأ أيضاً» لمقالات الدفعة نفسها تُحذف عند النشر المباشر لأن بلوجر يولّد الروابط.

## الإصلاحات
- تنظيف: توحيد مسار النشر مع مسار الـ XML فلا ازدواج في بناء المحتوى.
