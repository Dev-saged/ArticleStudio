# v0.11.1

## الإضافات
- زر «انشر المتوقف» في السجل والنشر: ينشر المقالات المصدّرة التي لم تُنشر من ملفاتك المحفوظة دون إعادة توليد.

## المميزات
- إعادة محاولة تلقائية (3 مرات) لطلبات GitHub عند انقطاع الشبكة أو ازدحام الخدمة.
- مهلات شبكة أطول للقراءة والكتابة تناسب صور الأغلفة الكبيرة.

## الإصلاحات
- «تعذّر التصدير: timeout»: كانت مهلة 10 ثوانٍ الافتراضية تقطع رفع الصور والنشر، فتتوقف مقالات الموقع.
