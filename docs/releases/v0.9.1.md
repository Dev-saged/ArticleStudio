# ArticleStudio v0.9.1

## الإضافات
- اختبار المزود يجرّب حتى ثلاثة نماذج قبل الحكم عليه، فلا يُظلم مزود لأن نموذجه الأول أُوقف.
- رسائل أخطاء المزودين بالعربية المفهومة (مفتاح مرفوض، يحتاج وسيلة دفع، النموذج لم يعد متاحاً، الحد مستهلك) بدل نص الخادم الخام.

## المميزات
- ألوان الحالة متدرجة: الأحمر فقط للمفتاح المرفوض، والذهبي للمشكلات المؤقتة.
- LongCat يقرأ نماذجه من الخادم بدل اسم ثابت؛ LLM7 يعمل بلا مفتاح فعلاً.

## الإصلاحات
- ظهور أغلب المزودين بالأحمر وعدّاد إخفاق متضخم: فحص JSON في «التعبئة التلقائية» كان يرمي خطأ فيُحسب على المزود. أصبح رد غير صالح يُجرَّب له التالي دون وصمه، والمحلل يقبل قوائم متنوعة الشكل.
