# ArticleStudio v0.1.0

## الإضافات
- هيكل التطبيق: Kotlin + Compose، Hilt + KSP، Room v1، kotlinx.serialization.
- شاشة «غرفة العمليات»: لوحة تكتيكية يتبادل فيها المزودون الكرة (معاينة ببيانات تجريبية).
- المقالات والمزودون والتصدير كشاشات أساس؛ مفاتيح المزودين تُحفظ مشفّرة عبر Android Keystore.
- شاشة الفحص الذاتي: اضغط عنوان «غرفة العمليات» خمس مرات متتالية.

## المميزات
- وضع فاتح وغامق بتبديل فوري، ألوان OKLCH من BrandConfig فقط.
- واجهة RTL بالكامل، أرقام بخط ثابت العرض، احترام إيقاف الحركات في النظام.
- أيقونة تكيفية (شعار B) مع طبقة أحادية اللون.

## الإصلاحات
- لا شيء (إصدار أول).
