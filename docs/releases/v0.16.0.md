# v0.16.0

## الإضافات
- طابور المشاركة مقسّم بأقسام مستقلة لكل منصة: إنستغرام أولاً ثم X ثم لينكدإن ثم فيسبوك وثريدز وتيليغرام وبلوسكي.
- «نشر الآن» لكل منشور، و«نشر الكل» لكل منصة بفاصل تحدده (1 أو 2 أو 5 أو 10 أو 30 دقيقة) ويُحفظ لكل منصة، و«إيقاف النشر الفوري».
- شريط ملخص أعلى الشاشة: بالانتظار، تحتاج تدخلك، نُشرت اليوم.
- سجل لكل منصة قابل للطي، ووقت النشر المجدول ظاهر على كل منشور (المقال المجدول يُنشر في موعده).

## المميزات
- النشر الفوري يتجاوز السقف اليومي ونافذة الساعات لأنه طلب صريح، وإيقافه يعيد المنشورات لقواعد الحساب.
- العامل الخلفي ينتظر المنشور التالي حتى دقيقتين فيكمل سلسلة الفاصل دون توقف.

## الإصلاحات
- تقسيم ملف شاشة المشاركة إلى ثلاثة ملفات أصغر دون تغيير السلوك.
- ترحيل Room 6→7 (عمود forced) مع اختبار.
