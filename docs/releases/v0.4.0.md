# ArticleStudio v0.4.0

## الإضافات
- حواف تلقائية: شريطا حافة صلبان أعلى الشاشة وأسفلها بارتفاع أشرطة النظام والقطع (الكاميرا) وإيماءات التنقل حسب كل جهاز، فلا يتداخل المحتوى معها، مع أيقونات شريط الحالة المناسبة للوضع الفاتح والغامق.
- تحديث داخل التطبيق: فحص تلقائي، بطاقة بملاحظات الإصدار، تنزيل بنسبة تقدّم، ثم تثبيت عبر مثبّت النظام. وزر «التحقق من التحديث» في شاشة المزودين.
- مجلد التطبيق: كل تصدير يُحفظ في التنزيلات ← ArticleStudio ← اسم التصدير، وفيه الـ XML والصور (أو ZIP الصور).
- SEO وGEO: صندوق «الجواب السريع» في أول المقال، قسم «أبرز النقاط»، جداول مقارنة، تاريخ ونسبة للتحرير، مخطط FAQPage بصيغة JSON-LD، وروابط «اقرأ أيضاً» داخلية من مقالاتك المنشورة فعلاً.
- تصميم صور أفخم: ملعب خافت وأشعة كشّافات وتظليل وإطار بزوايا ذهبية وهالة حول الرمز ورابط المدونة.

## المميزات
- عناوين 40-62 حرفاً ووصف 130-155 حرفاً، وجمل مستقلة قابلة للاقتباس وتعريف المصطلحات عند أول ذكر، لتناسب محركات الإجابة التوليدية.

## الإصلاحات
- تداخل المحتوى مع شريط الحالة وشريط التنقل.
- أيقونات شريط الحالة غير ظاهرة في الوضع الفاتح.
