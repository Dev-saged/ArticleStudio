# ArticleStudio v0.2.0

## الإضافات
- محرك التوليد الحقيقي: Cerebras وGroq وGemini وMistral وOpenRouter وCohere وPollinations (بلا مفتاح) ومزود مخصص، مع تبديل تلقائي وتبريد وذاكرة صحة.
- أوضاع التخطيط: أخبار حية من ESPN، مواضيع دائمة، أو مواضيعي (موضوع في كل سطر).
- خدمة أمامية بإشعار تقدّم وزر إيقاف: يستمر التوليد والتطبيق في الخلفية، ويستأنف تلقائياً من حيث توقف.
- رسم غلاف وبطاقة معلومات لكل مقال بخط عربي، ورفع الصور إلى GitHub بإيداع واحد.
- تصدير XML لبلوجر (نوع text/xml) مع حفظ في التنزيلات ومشاركة، وجدولة النشر بالساعات.
- تحرير العنوان والوصف والتصنيفات، إعادة توليد مقال، حذف، ودرجة جودة 0–100.
- فحص تحديث من GitHub Releases، تصدير واستيراد مفاتيح المزودين، وفحص التوكن.

## المميزات
- كل مقال يُحفظ في Room فور اكتماله؛ لا يضيع شيء عند إغلاق التطبيق.
- Room v2 بترحيل مرقّم 1→2 مع اختبار ترحيل.
- فحص ذاتي على الجهاز يغطي الآن الوسوم وXML ورسم الصور.

## الإصلاحات
- لا إصلاحات على إصدارات منشورة سابقاً (أصلحنا أثناء التطوير: أرقام معكوسة في الصور، نص SVG، تداخل البطاقة، انهيار Keystore).
