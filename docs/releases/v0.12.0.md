# v0.12.0

## الإضافات
- غرفة التحكم: الرئيسية تعرض كل المواقع كبطاقات حية (المرحلة والتقدم وعدد الجاهز ولم يُنشر ومنشور) مع إيقاف أو استئناف سريع من البطاقة.
- غرفة الموقع: الدخول لأي موقع بلمسة والخروج بزر الرجوع، وتتبع مرحلة العمل فيه بدقة.
- واجهة الكورة (لوحة المزودين) ثابتة في كل المواقع.

## المميزات
- توليد متوازٍ: لكل موقع مهمة مستقلة بحالتها وإيقافها واستئنافها؛ يمكن توليد مقالات لموقع والعمل على آخر في آن واحد (حتى 3 مقالات متزامنة).
- لا قفل للتنقل بين المواقع أثناء التوليد.
- شريط الحالة العلوي وإشعار الخدمة يذكران اسم الموقع عند تعدد المواقع.

## الإصلاحات
- التنقل لا يتطلب الضغط على «ولّد» أو «نشر» لتبديل الموقع.
- الموقع غير الرياضي كان يخفي واجهة الكورة؛ صارت ثابتة.
