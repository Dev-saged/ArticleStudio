# v0.11.0

## الإضافات
- مصادر متعددة للصور بتبديل تلقائي: Gemini، Together FLUX، Cloudflare FLUX، Pollinations، ثم صور فوتوغرافية من Pexels وPixabay، وأخيراً رسم SVG.
- مزودان جديدان للنص: GitHub Models وTogether AI (يعملان ضمن سلسلة التبديل نفسها).
- قسم «مصادر الصور» في شاشة المزودين بمفتاح واختبار وحالة لكل مصدر.

## المميزات
- كل مصدر متعثّر يُجمَّد مؤقتاً (دقيقتان للأعطال، عشر دقائق لتجاوز الحد، ساعة لرفض المفتاح) فلا يتوقف التوليد.
- الصورة المرفوضة (فارغة أو صغيرة) تُحسب إخفاقاً للمصدر وتنتقل السلسلة للتالي.
- إحصاءات نجاح وإخفاق ورسالة عربية واضحة لكل مصدر، والأحمر لرفض المفتاح فقط.

## الإصلاحات
- لا إصلاحات في هذا الإصدار.
