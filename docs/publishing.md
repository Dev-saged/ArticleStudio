# النشر المباشر على بلوجر

الدليل الكامل داخل التطبيق: تبويب «المواقع» ← زر «النشر» في بطاقة الموقع. هذا الملف نسخة مختصرة لمن تُسلَّم له النسخة.

## الطريقة 1: جسر Apps Script (الأسرع، بلا Google Cloud)
1. script.google.com بحساب مالك المدونة ← مشروع جديد.
2. الصق الكود الذي ينسخه التطبيق (فيه سرّ خاص بالموقع).
3. الخدمات (+) ← Blogger API ← إضافة.
4. نشر ← عملية نشر جديدة ← الترس بجانب «اختيار النوع» ← «تطبيق الويب».
5. تنفيذ التطبيق كـ: أنا. من لديه حق الوصول: أي شخص. ثم «نشر».
6. منح الصلاحيات ← حسابك ← متقدم ← الانتقال إلى المشروع (غير آمن) ← السماح.
7. الصق الرابط المنتهي بـ /exec في التطبيق ثم «حفظ واختبار».

## الطريقة 2: تسجيل الدخول بجوجل (أنعم بعد الإعداد)
1. مشروع في Google Cloud ← تفعيل Blogger API v3.
2. Google Auth Platform: جمهور External، أضف بريدك مستخدماً تجريبياً، وأضف صلاحية `auth/blogger`.
3. Clients ← Create client ← Android: اسم الحزمة وبصمة SHA-1 (يعرضهما التطبيق).
4. في التطبيق: «ربط حساب جوجل» ثم «اختبار الاتصال».

## ملاحظات
- الحالة الافتراضية «مسودة»؛ راجع المنشورات في بلوجر ثم انشرها.
- النشر المباشر يحتاج «الرفع التلقائي» لصور المقالات.
- الـ API لا يضبط الرابط الدائم ولا وصف الميتا؛ للتحكم فيهما استورد ملف XML.
